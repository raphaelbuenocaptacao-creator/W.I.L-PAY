# W.I.L Pay

PWA financeiro de crédito direto com identidade preta e dourada, autenticação Neon, cadastro com PIX, solicitação de crédito, regras configuráveis, aprovação administrativa, parcelas, pagamentos, W.I.L Score (1–1000) e localização autorizada com histórico.

## Fluxo
Cliente: criar conta → completar cadastro/PIX → solicitar crédito → acompanhar aprovação → visualizar parcelas → construir score.

Administrador: entrar na Central → configurar regras → aprovar/recusar → registrar pagamentos → acompanhar carteira, clientes, score e mapa autorizado.

## Stack
React + Vite + Neon Auth + Neon Postgres + PWA + GitHub Pages.
